# Reflection

This laboratory introduced me to using a cloud-based Linux environment through KillerCoda. I learned how to create a Linux user, provide sudo privileges, log in to a user account, and navigate the Linux file system.

I also learned how to gather information about the operating system, kernel, CPU, memory, and available disk space using Linux commands. Creating and organizing directories and Markdown files helped me understand the importance of maintaining a structured workspace.

Another important part of this activity was preparing a GitHub portfolio. This repository will allow me to document and organize my Cloud Computing laboratory activities throughout the semester.

Overall, this laboratory helped me strengthen my understanding of Linux administration, technical documentation, and version-controlled portfolio management. These skills will be useful in future cloud computing and infrastructure activities.
