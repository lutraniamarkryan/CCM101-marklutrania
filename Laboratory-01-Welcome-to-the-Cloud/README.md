# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduces the Linux operating system through the KillerCoda cloud-based playground. The activity focuses on basic Linux administration, system information gathering, file organization, Markdown documentation, and GitHub portfolio management.

## Objectives

- Access a cloud-based Linux environment using KillerCoda.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Create and manage Linux users.
- Organize files and directories.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed Ubuntu 24.04 through KillerCoda.
2. Created the `marklutrania` Linux user.
3. Added the user to the sudo group.
4. Logged in using the new user account.
5. Collected Linux system information.
6. Created and organized directories and Markdown files.
7. Prepared the Cloud Computing portfolio structure.

## Linux Commands Used

- `whoami` – Displays the current username.
- `pwd` – Displays the current working directory.
- `hostname` – Displays the system hostname.
- `adduser` – Creates a new Linux user.
- `usermod` – Modifies user account settings.
- `su` – Switches to another user account.
- `cat` – Displays file contents.
- `uname` – Displays kernel information.
- `lscpu` – Displays CPU information.
- `free` – Displays memory information.
- `df` – Displays disk space information.
- `mkdir` – Creates directories.
- `touch` – Creates files.
- `nano` – Edits text files.
- `cp` – Copies files.
- `find` – Searches for and displays files and directories.

## Skills Learned

- File and directory management
