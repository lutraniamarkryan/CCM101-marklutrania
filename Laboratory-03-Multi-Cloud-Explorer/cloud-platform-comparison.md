## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest selections of cloud services. It provides services covering computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works closely with Windows Server, Microsoft 365, Active Directory, and other Microsoft enterprise products.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, and Kubernetes. Its AI services and Google Kubernetes Engine provide powerful tools for developing and managing cloud-native applications.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a broad range of services and supports many different types of workloads. Its extensive infrastructure and service selection make it flexible for both small projects and large enterprise applications.
