# Mission 3 – Multi-Cloud Explorer

## Linux Server Investigation

### Operating System

The Linux server operating system was identified using the `/etc/os-release` file.

### CPU Information

CPU information was collected using the `lscpu` command. It provides information about the processor architecture, CPU model, cores, and processing units.

### Memory

Memory information was collected using the `free -h` command. It displays the total, used, free, and available memory.

### Disk Space

Disk space information was collected using the `df -h` command. It displays filesystem storage capacity and available space.

## Cloud Migration

If this Linux server were migrated to the cloud, the following services could host it:

| Cloud Provider | Service |
|---|---|
| AWS | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machines |
| Google Cloud | Compute Engine |

These services provide virtual machines capable of running Linux operating systems and applications.
