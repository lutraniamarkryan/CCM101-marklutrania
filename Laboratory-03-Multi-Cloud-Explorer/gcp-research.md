# Google Cloud Platform Research

## Brief Overview
Google Cloud is a cloud computing platform that provides infrastructure, storage, databases, networking, artificial intelligence, machine learning, analytics, and application development services.

## Global Infrastructure
Google Cloud operates a global infrastructure consisting of regions and zones distributed around the world. This supports high availability and global application deployment.

## Cloud Management Console
Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services
1. **Compute Engine** – Provides virtual machines for applications and workloads.
2. **Cloud Storage** – Provides scalable object storage.
3. **Cloud SQL** – Provides managed relational databases.
4. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes for containerized applications.

## Three Advantages
1. Google Cloud has strong artificial intelligence and machine learning capabilities.
2. Google Cloud provides strong Kubernetes and container technologies.
3. Google Cloud has a global infrastructure suitable for worldwide applications.

## Typical Enterprise Use Cases
Google Cloud is commonly used for artificial intelligence, machine learning, data analytics, Kubernetes applications, web applications, data storage, and global enterprise workloads.
