# Mission 3 Reflection

This mission helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform and how cloud platforms can be selected based on business requirements. The platform that impressed me the most was AWS because of its wide range of services, global infrastructure, and ability to support different types of organizations. However, Azure and Google Cloud also provide strong capabilities for specific business needs.

AWS, Azure, and Google Cloud share many similarities. All three provide virtual machines, storage, databases, networking, identity management, security, monitoring, and other cloud services. They also provide global infrastructure that allows organizations to deploy applications and services with scalability and high availability.

Business requirements strongly influence cloud platform selection. A company should consider its budget, existing technologies, workload requirements, location, security needs, scalability, and technical expertise. For example, Azure is a strong choice for an organization that already depends heavily on Microsoft technologies, while Google Cloud is attractive for AI, machine learning, and Kubernetes workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The best solution depends on understanding the client's goals and matching those requirements with the appropriate cloud services.

My GitHub Cloud Computing Portfolio improved significantly after completing this mission. I added research about three major cloud providers, created comparison tables, analyzed different business scenarios, documented Linux server information, and maintained a meaningful commit history. This activity also improved my understanding of how technical cloud decisions can support real business needs.
