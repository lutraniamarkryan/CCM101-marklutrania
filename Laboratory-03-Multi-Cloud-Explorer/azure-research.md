# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform developed by Microsoft that provides computing, storage, networking, databases, artificial intelligence, security, and other cloud services.

## Global Infrastructure
Azure operates through a worldwide network of cloud regions and availability infrastructure. Organizations can deploy applications across different geographic locations.

## Cloud Management Console
The Azure Portal is a web-based management interface used to create, configure, monitor, and manage Azure resources.

## Four Core Services
1. **Azure Virtual Machines** – Provides virtual machines for running applications.
2. **Azure Blob Storage** – Provides scalable object storage.
3. **Azure SQL Database** – Provides a managed relational database.
4. **Azure Virtual Network** – Provides networking capabilities for Azure resources.

## Three Advantages
1. Azure integrates strongly with Microsoft technologies.
2. Azure provides extensive enterprise and hybrid-cloud capabilities.
3. Azure offers many AI, security, database, and infrastructure services.

## Typical Enterprise Use Cases
Azure is commonly used for Windows workloads, enterprise applications, Microsoft environments, hybrid cloud infrastructure, databases, artificial intelligence, analytics, and web applications.
